# India's Inventors Presentation

An animated HTML presentation about Indian inventors (in Dutch), built with the [frontend-slides](https://github.com/anthropics/claude-code) plugin.

## Structure

- `docs/` — published presentation (`index.html`) and its images, ready to be served (e.g. via GitHub Pages)
- `outputs/` — generated build output from the slides plugin
- `work/` — working files
- `.frontend-slides/` — plugin assets, including slide previews

## Viewing

Open `docs/index.html` in a browser, or serve the `docs/` folder as a static site.
